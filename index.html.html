Readouts describe the subject nearest the centre of frame. Objects named Actor, Stand-in, Character or Talent in Blender are added automatically.

Exporting a set from Blender
  1. File › Export › glTF 2.0, Format: glTF Binary (.glb).
  2. Under Include, tick Cameras and Punctual Lights.
  3. Area lights don't export. Use Point, Spot or Sun lights for practicals and windows.
  4. Leave Compression (Draco) off. This page can't decode it.
  5. Name actor objects "Actor…" or "Stand-in…" so they become subjects.
  6. Procedural shaders don't export: use image textures or plain colors.
  7. Keep it under about 500k triangles so phones stay smooth.
